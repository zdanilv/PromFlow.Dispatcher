# Чек-лист снимков интерфейса PromFlow.Dispatcher

Это задачи для будущего обновления README, перенесённые из скрытых комментариев исходной версии. Снимки пока не созданы; пути ниже обозначают ожидаемые результаты, а не существующие файлы.

- [ ] `docs/images/route-map-overview.png` — режим `user`: Route Map со схемой маршрута, карточками оборудования, TopBar и правой панелью уведомлений.
- [ ] `docs/images/admin-workspace-tabs.png` — режим `admin`: Workspace с фактическими вкладками `Route Map`, `SignalId ↔ Modbus`, `Менеджер тревог`, `Modbus TCP`.
- [ ] `docs/images/route-map-settings.png` — режим `admin`: открытый диалог настроек Route Map с видимыми основными разделами редактирования.
- [ ] `docs/images/signalid-modbus-mapping.png` — режим `admin`: вкладка `SignalId ↔ Modbus` с примером привязки доменного SignalId к Modbus-точке.
- [ ] `docs/images/modbus-tcp-runtime.png` — режим `admin`: вкладка `Modbus TCP` с состоянием общего runtime и настройками ролей соединения.
- [ ] `docs/images/alarm-manager-and-notification.png` — менеджер тревог в режиме `admin` и соответствующее уведомление Route Map; если оба состояния не помещаются на одном снимке, подготовить согласованную композицию из реальных снимков.

Перед выполнением каждого пункта сверить экран и названия с текущим UI, скрыть адреса PLC, имена узлов, учётные и служебные данные и проверить читаемость. Использовать только реальные снимки текущей версии; не создавать заглушки. Ссылку в README добавлять лишь после появления и проверки соответствующего файла. Получение снимков не должно отправлять команды на промышленное оборудование: использовать безопасные тестовые данные и изолированную среду.
